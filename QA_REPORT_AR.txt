تقرير فحص الإصدار 1.5.76 — صدى العراق
=====================================

التحديثات
---------
- إضافة بطاقة «طلبات صدى العراق» في آخر الصفحة الرئيسية، تقرأ الإجمالي من سجلات الطلبات في Firebase ودفتر الطلبات المحلي، مع إزالة التكرار وعدم عرض رقم تخميني عند تعذر المصدر.
- إعادة تحميل قائمة المستخدمين من مسار خادم محمي بدلاً من تركها فارغة عند عدم جاهزية Firebase SDK في المتصفح.
- إظهار سجلات Base44 التي لا تطابق حساباً حياً كسجلات قديمة للقراءة فقط، مع عرض الرصيد الموروث وعدد الطلبات المتاح.
- إضافة مسار رفع ZIP خاص ومحمي، يتحقق من سلامة الأرشيف وترويسة SQLite وتفرّد المعرّفات وروابط الطلبات بالمستخدمين قبل السماح بالمعاينة.
- دمج الطلبات القديمة بمفاتيح ثابتة ووسم legacyHistory للقراءة فقط لتجنب إرسالها إلى المزوّد من جديد أو إحداث شحن/خصم/استرداد جديد.
- ربط الطلبات بالحساب الحالي عند مطابقة البريد بشكل وحيد؛ الحسابات غير المطابقة لا تتحول إلى حسابات تسجيل دخول تلقائياً.
- تحديث عدّاد الطلبات التاريخية للحسابات المطابقة مع علامة ثابتة تمنع مضاعفة العد عند إعادة المحاولة.
- منع استبدال الأرصدة الحالية ذات النشاط؛ الرصيد التاريخي لا يستعاد تلقائياً إلا في الحالات الآمنة، والباقي يظهر للمراجعة.
- إصلاح اختيار إعداد الترحيب الأحدث عبر updatedAt، وجعل الخادم يرجع فشلاً واضحاً إذا لم يتأكد التخزين الدائم.
- تحسين تشخيص إعدادات Telegram وحفظ التوكن مشفراً، مع رفض الحفظ عندما لا يتوفر مفتاح تشفير ثابت موثوق بدلاً من حفظ التوكن مكشوفاً.
- توحيد وسم الإصدار وBuild ID إلى 1.5.76، بما في ذلك ترويسة استيراد قاعدة البيانات.

الاختبارات المنفذة
------------------
- node --check server.js: ناجح.
- فحص كتل JavaScript المضمنة في index.html: 54 كتلة، دون أخطاء صياغة.
- فحص ZIP التصدير المرفق: CRC سليم؛ ملف SQLite اجتاز PRAGMA integrity_check؛ الجداول فيها 822 مستخدماً و2,840 طلباً و1,129 معاملة.
- اختبار API على خادم Firebase تجريبي محلي: نجح تسجيل دخول مشرف الاختبار، وحصلت بطاقة الموقع على عدد حقيقي من 3 طلبات تجريبية.
- اختبار إعدادات الترحيب في قاعدة اختبار: نجح حفظ روابط HTTPS وقراءتها بعد الحفظ.
- اختبار Telegram في قاعدة اختبار: نجح حفظ التوكن المشفّر وقراءة حالة الإعدادات. هذا تحقق من مسار التخزين فقط وليس من Telegram الفعلي.
- اختبارات مسارات Telegram (getMe، اختبار قناة التفعيلات، واختبار قناة التأخير) نجحت مقابل API محلية محاكية، مع التأكد من تمرير Chat ID المناسب لكل قناة؛ لم يتم إرسال رسالة إلى قناة Telegram حقيقية.
- اختبار مراقب التأخير في المحاكاة: لم يرسل أي إشعار عن طلب تاريخي مستورد (legacyHistory)، بينما أرسل إنذار 3 ساعات للطلب الحي المتأخر إلى قناة التأخير المحددة.
- اختبار استيراد ملف التصدير الحقيقي إلى قاعدة Firebase تجريبية: قُبلت 822 مستخدماً و2,840 طلباً و1,129 معاملة، وتحققت سلامة الروابط قبل الحفظ.
- عند تطبيق الاستيراد في الاختبار التجريبي، أضيفت 2,840 طلباً؛ وعند رفع الملف مجدداً أظهرت المعاينة 0 طلبات جديدة و2,840 موجودة مسبقاً.
- بعد الاستيراد التجريبي، أظهر مسار إجمالي الطلبات العدد 2,840، وعرض مسار المستخدمين 3 حسابات اختبار حية و819 سجلّاً تاريخياً غير مطابق للقراءة فقط. الأرقام الخاصة بالمطابقة تخص بيانات الاختبار المنشأة في بيئة المحاكاة ولا تتنبأ بنتيجة حسابات الإنتاج.

حدود مهمة — يجب قراءتها قبل النشر
--------------------------------
- الاختبارات استخدمت محاكاة Firebase محلية، ولم يتم الاتصال بقاعدة Firebase الإنتاجية أو تعديلها.
- لم يتم إرسال رسالة إلى Telegram الحقيقي لعدم توفر توكن الإنتاج ومعرّفات القنوات؛ يجب استخدام زري اختبار اتصال البوت واختبار القناتين بعد النشر.
- لا يحتوي ملف Base44 المصدر على سجلات دخول منفصلة أو كلمات مرور قابلة للنقل.
- لا تُكتب بيانات قاعدة التصدير داخل مجلد عام أو داخل الأرشيف البرمجي. بعد نشر هذا الإصدار، ارفع SadaIraq_Database_Export.zip من لوحة الإدارة > الأرباح > ربط قاعدة البيانات القديمة، راجع المعاينة، ثم اضغط تأكيد الدمج.
- يجب الحفاظ على قاعدة Firebase الحالية وRailway Volume ومسار DATA الحالي. لا تربط التطبيق بمجلد بيانات جديد أو فارغ.
- لحفظ Telegram بأمان عبر واجهة الإدارة، عيّن SESSION_SECRET عشوائياً وثابتاً وطويلاً (يفضل 64 محرفاً)، أو SADA_ENCRYPTION_KEY عشوائياً وثابتاً، أو استخدم Railway Volume فعلياً ودائماً. لا ترسل هذه القيم أو Bot Token في المحادثة.
- إنشاء ZIP لا ينشر الإصدار إلى Railway تلقائياً؛ يلزم رفعه إلى GitHub/وسيلة النشر الحالية، ثم التأكد من أن Build ID المعروض في /api/health هو SADA-1.5.76-HOME-ORDERS-ADMIN-TELEGRAM-PERSISTENCE-20261010.
