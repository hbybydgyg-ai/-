الإصدار 1.5.64 — WhatsApp + Telegram + Google Auth
- زر واتساب: يُنقل إلى body مباشرةً، مع z-index عالٍ جداً وخلفية معتمة ومقاس ثابت، ويختفي عند فتح النافذة المنبثقة حتى لا يغطي عناصرها.
- Telegram: إشعار طلب جديد إلى الوجهة الأساسية المحددة في TELEGRAM_CHAT_ID، ويمكن إضافة وجهات مستقلة عبر TELEGRAM_EXTRA_CHAT_IDS. مراقب الطلبات يعمل كل دقيقة، ويصعد التحذير عند 3 و6 و12 ساعة للطلبات غير النهائية، مع حفظ علامة كل مستوى لتفادي التكرار.
- حماية التوكن: لا يوضع بوت توكن داخل HTML أو الحزمة؛ ضع توكناً جديداً بعد إلغاء التوكن المكشوف داخل Railway Variables باسم TELEGRAM_BOT_TOKEN. اجعل TELEGRAM_CHAT_ID=@hddjh55 وأضف البوت كمسؤول قادر على نشر الرسائل في القناة. الرقم الذي يسبق النقطتين في البوت توكن هو Bot ID وليس بالضرورة Chat ID للمحادثة.
- تسجيل Google: تحقق الخادم من ID token باستخدام Google Auth Library ولا يثق في بيانات يرسلها المتصفح وحدها. يحتاج GOOGLE_CLIENT_ID من Google Cloud OAuth Web Client، وإضافة https://3dce.up.railway.app إلى Authorized JavaScript origins.
- CAPTCHA: سؤال جمع صغير مرتبط بجلسة/عنوان الشبكة، أحادي الاستخدام، بمدة صلاحية خمس دقائق، مع تحديد معدل الطلبات.
- التخزين: لحفظ ملفات الحسابات والحالات بين إصدارات Railway، اربط Volume دائمًا أو تأكد من صلاحية الكتابة إلى Firebase.

متغيرات Railway المطلوبة/الاختيارية:

TELEGRAM_EXTRA_CHAT_IDS=

GOOGLE_CLIENT_ID=ضع_WEB_CLIENT_ID_من_Google_Cloud
SESSION_SECRET=ضع_قيمة_عشوائية_طويلة_وفريدة

============================================================
مراجعة 1.5.67 — إحصائيات الاستخدام، شاشة البداية، المكافآت والإشعارات
============================================================

- شاشة البداية توضع أول عنصر مرئي في الصفحة وتعرض الشعار ومؤشر تحميل لمدة 3 ثوانٍ، ثم تزال قبل إظهار الواجهة المعتادة. تسجيل دخول الجلسة يستمر بالتوازي؛ كما يبدأ الخادم الاستماع قبل انتظار مزامنة Firebase في الخلفية.
- الصفحة الرئيسية تعرض إحصائيات الحساب من الطلبات المحلية وطلبات Firebase عند توفرها: عدد الطلبات، إجمالي المنفق، الرصيد الحالي، مجموع الاستردادات المؤكدة، المكافآت المعتمدة وعدد الإشعارات غير المقروءة. عند تعذر قاعدة البيانات يعتمد النظام على البيانات المحلية ويُسجّل التحذير بدلاً من الادعاء أن القراءة الخارجية نجحت.
- صفحة «اربح رصيد مجاناً» تستقبل روابط فيديو TikTok وYouTube وInstagram وFacebook، وتطبق حدود المتابعين والمشاهدات وسقف 50 دولاراً للحساب. المكافآت تبقى بانتظار مراجعة الإدارة؛ لا يضاف الرصيد لمجرد تقديم النموذج.
- صفحة «الإشعارات» تعرض إشعارات الطلبات الجديدة وتغييرات الحالة والمكافآت مع مؤشر غير مقروء وإمكانية فتح الطلب المرتبط عند توفره.
- سعر المزوّد يتزامن تلقائياً حسب الإعداد المحفوظ؛ القيمة الافتراضية للحسابات الجديدة ساعة واحدة، مع خيارات 1/3/6/12/24 ساعة. يستند سعر البيع إلى تكلفة المزود الأصلية مع نسبة الربح المحددة، ويتجاوز السعر الصفري غير المتوقع لخدمة مدفوعة بدلاً من تحويلها إلى مجانية.
- الاسترداد الكامل بعد تأكيد حالة الإلغاء، والاسترداد الجزئي من الكمية المتبقية التي يؤكدها المزوّد. تُستخدم معاملة Firebase بمفتاح ثابت لمنع تكرار الرصيد. لا يتم الرد إن كانت بيانات الكمية غير موجودة أو غير موثوقة، ولا يتم رد شيء لحالة جزئية تُظهر remains=0.
