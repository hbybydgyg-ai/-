صدى العراق — ملاحظات الإصدار 1.5.79
===================================

التحديثات
---------
- زر «حسابي» يعرض البريد المستخدم بالحساب وحالة التوثيق ورقم الهاتف وتاريخ التسجيل وآخر دخول، وإحصائيات الطلبات المكتملة والجارية والإجمالية، والإنفاق والاسترداد والمكافآت والرصيد، مع أدوات تغيير/تأكيد البريد وتغيير كلمة السر عبر رمز البريد.
- ترتيب شريط المستخدم: «إنشاء طلب» أولاً، ثم «حسابي» ثانياً.
- أداة استيراد قاعدة Base44 ظاهرة مباشرة في لوحة الإدارة > المستخدمون، وتعرض ملخص الحسابات الحالية والسجلات القديمة وإجمالي المعروض. يمكن رفع قاعدة ZIP كاملة ومعاينتها ثم تأكيد الدمج دفعة واحدة.
- أسماء الخدمات من المزود تُقرأ من حقول الاسم المتاحة وتُحافظ على الاسم الأصلي. عند رجوع اسم عام فقط، يُستعمل «خدمة رقم <معرّف>» حتى لا تنقلب جميع الخدمات إلى الاسم العام «خدمة». كما أن مزامنة الأسعار تصلح الاسم المحفوظ العام فقط إذا توفر اسم حقيقي لدى المزود، ولا تستبدل الاسم المخصص الصحيح.
- قائمة المستخدمين تعاد من نقطة API في الخادم وتشمل جميع الصفوف المتاحة، بدلاً من اعتماد الواجهة وحدها على جلسة Firebase في المتصفح.

استعادة قاعدة Base44
--------------------
1. انشر المشروع مع الحفاظ على Firebase الحالي وVolume الحالي.
2. افتح لوحة الإدارة > المستخدمون.
3. اختر `SadaIraq_Database_Export.zip` من أداة استعادة قاعدة Base44.
4. راجع المعاينة ثم أكّد الدمج. لا تضغط تأكيد إذا أظهر الفحص خطأ.
5. حدث قائمة المستخدمين. تظهر الحسابات المطابقة للحسابات الحية، والسجلات غير المطابقة للقراءة فقط. لا يمكن نقل كلمات مرور Base44 القديمة.

التخزين والخصوصية
-----------------
لا يحتوي هذا ZIP على ملف قاعدة البيانات الخاصة أو بيانات المستخدمين الحقيقية. لا تضع ملف التصدير في GitHub أو public. بعد الاستيراد تُحفظ بيانات السجلات القديمة داخل DATA الخاص بالخادم. ثبّت مجلد البيانات باستخدام Railway Volume على `/data` واضبط `SADA_DATA_DIR=/data` حتى تبقى البيانات بعد النشر، مع عدم استبدال أي Volume يحتوي بيانات حية.

تيليجرام
--------
لا يُضمّن التوكن داخل المشروع أو الاستجابة. أي توكن سبق مشاركته يجب إلغاؤه وإنشاء آخر جديد. خزّن `SADA_ENCRYPTION_KEY` أو `SESSION_SECRET` كسِر ثابت قوي داخل Railway Variables، ولا تغيّره دون خطة، ثم أعد النشر واختبر القناة الفعلية.

حدود التحقق
-----------
هذا الإصدار لا يتصل تلقائياً ببيئة Railway أو قاعدة Firebase الإنتاجية. تحقق من نتائج الدمج بعد رفع ZIP من داخل لوحة الإدارة. لم يتم اختبار وصول رسالة إلى قناة Telegram الإنتاجية ضمن الفحص المحلي.
