صدى العراق — نسخة Railway v1.3.6

التشغيل:
1) ارفع المشروع إلى GitHub مرة واحدة واربط المستودع بخدمة Railway الحالية.
2) لا تنشئ مشروع Railway جديد عند كل تحديث.
3) كل تحديث لاحق: عدّل الملفات في GitHub ثم Commit/Push، وسيعاد النشر على نفس الخدمة والرابط.
4) ضع ADMIN_EMAIL و ADMIN_PASSWORD كـ Variables في Railway عند الحاجة؛ للقيم الافتراضية يعمل الحساب المرفق أيضاً.
5) لا تضع مفاتيح مزودي SMM داخل GitHub؛ أضفها من لوحة الإدارة.

الملفات المهمة:
- index.html: واجهة الموقع.
- server.js: خادم Railway وواجهات API.
- data/: بيانات محلية احتياطية للمشروع.
- sadairaq-logo.jpg: شعار صدى العراق.

الشحن:
- آسياسيل: الرقم الثابت للشحن محفوظ في الخادم فقط ولا يظهر للمستخدم.
- أثير: تحويل يدوي إلى 07903221783 مع إثبات التحويل للدعم.
- سعر الصرف الثابت للشحن: 1 USD = 1,250 IQD.
- 5,000 IQD = 4.00 USD.

تنظيف البداية:
لوحة الإدارة تحتوي زر حذف جميع البيانات وإعادة ترقيم الطلبات من 1.


تحديث v1.2.0:
- الطلبات أصبحت تمر عبر واجهة Railway المحمية ثم إلى API المزود الحقيقي، ولا يُحفظ الطلب كناجح قبل استلام رقم طلب حقيقي من المزود.
- تحديث الحالة والإلغاء للمستخدم يتم عبر API المزود فقط حسب ما يدعمه المزود.
- رصيد المزود المعروض في الإدارة يُجلب من API الحقيقي.
- استيراد الخدمات يعرض كتالوج المزود بشكل منفصل ويضيف الخدمات المحددة فقط إلى كتالوج الموقع.
- تم إلغاء التنظيف التلقائي عند تسجيل دخول الإدارة؛ حذف البيانات متاح فقط من زر التنظيف الصريح داخل الإدارة.
- الإصدار الظاهر للمستخدم: 1.2.0.


تحديث v1.3.6: لوحة إدارة مبسطة، إعداد واتساب قابل للحفظ، رصيد مزود حقيقي عبر API، وإنشاء/تحديث/إلغاء الطلبات عبر API الحقيقي دون Manual Save.


تحديث 1.3.1: إصلاح نهائي لمشكلة تجمد/خروج واجهة التطبيق عن موضع الشاشة بعد تسجيل الدخول، مع تثبيت التطبيق على حجم الشاشة وجعل منطقة المحتوى الداخلية هي منطقة التمرير.
