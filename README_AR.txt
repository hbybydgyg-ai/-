صدى العراق — الإصدار 1.5.85
============================

هذا الإصدار يضم ملف قاعدة Base44 الأصلي داخل المسار database/SadaIraq_Database_Export.zip ويقرأه الخادم تلقائياً عند أول تشغيل. لا يحتاج SADA_LEGACY_SEED_KEY أو رفع ملف قاعدة البيانات من لوحة الإدارة.

عند بدء التشغيل:
- يفحص الخادم سلامة ZIP ورأس SQLite، ويتحقق من أعداد السجلات ومعرّفاتها والعلاقة بين الطلبات والمستخدمين.
- ينشئ ملفات حسابات المستخدمين القديمة الناقصة في Firebase كحسابات عادية، مع إبقاء كلمات المرور فارغة ووضع needsPasswordSetup=true لأن التصدير لم يتضمن كلمات المرور.
- يدمج الطلبات والمعاملات القديمة دون تكرارها، ويحافظ على الحسابات والبيانات الموجودة مسبقاً ولا يستبدل رصيد المستخدم النشط عشوائياً.
- يخزن معلومات الترحيل حتى يستطيع إكماله عند انقطاع اتصال قاعدة البيانات أو إعادة تشغيل الخادم.

النقل إلى استضافة أخرى
---------------------
1) ارفع ملف ZIP الخاص بالإصدار كاملاً كما هو؛ لا تحذف مجلد database.
2) يجب أن تشير FIREBASE_DATABASE_URL إلى قاعدة بيانات Firebase التي تريد استعمالها. إذا استُخدمت قاعدة جديدة فارغة، سيبدأ الدمج التلقائي عند تشغيل الخادم بعد نجاح الاتصال بها.
3) عند إعادة النشر على القاعدة نفسها، يفحص الخادم السجلات الموجودة ويكمل الناقص فقط، ولا يعيد إنشاء طلبات مكررة.
4) استمر باستخدام زر «تنزيل قاعدة الموقع كاملة» لحفظ آخر بيانات التشغيل بما فيها حسابات وطلبات أحدث من التصدير القديم. ملف التصدير المضمّن يمثل لقطة مؤرخة بتاريخ 2026-10-10، وليس بديلاً عن نسخ احتياطية دورية.

مهم جداً للخصوصية
-----------------
الملف المضمّن يحتوي بيانات شخصية وسجلات طلبات ومعاملات. لا ترفع المشروع أو ZIP إلى مستودع GitHub عام أو مكان يستطيع الآخرون تنزيله. استخدم مستودعاً خاصاً، أو سلّم الملف مباشرة إلى الاستضافة. لا تشارك ملف النسخة الاحتياطية.

كلمات المرور
------------
تصدير Base44 لا يحتوي كلمات المرور أو تجزئاتها الأصلية؛ لذلك تُستعاد بيانات الحساب لكن لا يمكن استرجاع كلمة المرور القديمة. يمكن للمستخدم تعيين كلمة مرور جديدة من خلال استعادة كلمة المرور عند تهيئة البريد الإلكتروني وإعداد خدمة البريد. لا توجد كلمة مرور مشتركة أو عشوائية أضيفت للحسابات.

إعدادات التشغيل
---------------
- Node.js 20 أو أحدث.
- شغّل بواسطة npm start.
- يجب تهيئة قاعدة Firebase الصحيحة في FIREBASE_DATABASE_URL إذا لم تكن تستخدم القيمة الافتراضية للمشروع.
- لا يحتوي هذا الإصدار على توكن Telegram أو مفاتيح مزوّدين سرية.

التحقق
------
يجب أن يعرض /api/health الإصدار 1.5.85 ومعرّف البناء SADA-1.5.85-BUNDLED-DATABASE-AUTO-RESTORE-20261011 وdeploymentConsistent=true. حالة الترحيل تتوفر في ملف data/legacy_seed_bootstrap_status.json وعلى مسار إدارة استيراد قاعدة البيانات.
