تقرير فحص الإصدار 1.5.75 — صدى العراق
=====================================

التحديثات
---------
- إضافة أداة إدارة محمية لرفع ملف ZIP القديم وفحص سلامته قبل الترحيل.
- لا توجد بيانات مستخدمين أو طلبات قديمة مضمنة في كود المصدر أو مجلد عام.
- دمج الطلبات القديمة إلى Firebase بمفاتيح ثابتة وبعلامة legacyHistory لمنع إعادة الإضافة.
- ربط المستخدمين بالبريد المطابق فقط؛ الحسابات غير المطابقة تبقى سجلات تاريخية للإدارة ولا يُفترض أنها تستطيع تسجيل الدخول بكلمة مرور Base44.
- عرض الطلبات التاريخية للقراءة فقط، وإزالة هوية المزود التنفيذية عنها لتجنب إعادة إرسال طلب قديم للمزود.
- مزامنة totalOrders في حساب المستخدم مع عدد الطلبات التاريخية المستوردة، مع علامة legacyBase44OrdersCount تمنع احتساب العدّاد مرتين عند إعادة الاستيراد أو إعادة المحاولة.
- إضافة تقرير «أكثر المستخدمين طلباً» بالاعتماد على سجل الطلبات الحية والقديمة، ويُحتسب كل طلب جديد بعد الترحيل بمقدار واحد.
- استعادة الرصيد القديم الموجب فقط للحساب المطابق الذي لا يملك رصيداً أو نشاطاً حالياً، مع تحويل 1 USD = 1,250 IQD. الرصيد الحالي والنشاط الحالي محفوظان؛ الرصيد السلبي يتطلب مراجعة بشرية.
- إدراج الطلبات من Firebase في قائمة طلبات الإدارة مع سجلات الخادم المحلية، مع منع التكرار بين المصدرين.

فحوص السكون وسلامة البيانات
---------------------------
- node --check server.js: ناجح.
- node --check api-addon.js: ناجح.
- فحص JavaScript المضمن في index.html: 57 كتلة، جميعها اجتازت فحص الصياغة.
- فحص ملف التصدير: 822 مستخدماً، و2,840 طلباً، و1,129 معاملة وفق الملفات الفعلية في ZIP.
- مسارات API الخاصة بالرفع والفحص والدمج والإحصائيات تتطلب جلسة مشرف.
- اختبار تكاملي بقاعدة Firebase اختبارية محلية (وليست قاعدة الإنتاج): نجح رفع ZIP والتحقق من CRC32 وترويسة SQLite والعلاقات، ثم المعاينة والدمج.
- في الاختبار المحلي التجريبي، أُضيفت 2,840 طلباً تاريخياً مرة واحدة، وطابقت 822 حساباً تجريبياً، وتمت مزامنة عداد 386 مستخدماً لديهم طلبات. لم تسجل أخطاء في تحديث العدادات أو في مسار استعادة الأرصدة التجريبي.
- إعادة رفع ZIP وإعادة الدمج أعادت 0 طلبات جديدة، وأبقت 2,840 سجلاً تاريخياً دون مضاعفتها أو زيادة عدادات المستخدمين مرة ثانية.
- تمت محاكاة إضافة طلب جديد بعد الترحيل؛ زاد العدد المحسوب لذلك المستخدم بمقدار واحد (مثال: 1,032 تاريخياً + 1 جديد = 1,033).

حدود مهمة
----------
- هذه الاختبارات تمت باستخدام قاعدة اختبار محلية؛ لم يتم الاتصال بقاعدة Firebase الإنتاجية أو تعديل أرصدتها أو طلباتها أثناء تجهيز الإصدار.
- بعد نشر الإصدار على Railway مع الإبقاء على قاعدة Firebase الحالية والـVolume ومسار DATA الحالي، يجب على المشرف رفع SadaIraq_Database_Export.zip من لوحة الإدارة، مراجعة المعاينة، ثم تأكيد الدمج بنفسه.
- لا تحتوي قاعدة Base44 المرفقة على سجل دخول منفصل أو كلمات مرور قابلة للنقل.
- لا يتم استيراد سجلات المعاملات القديمة إلى سجل الرصيد الحي لمنع تكرار الشحنات والاستردادات؛ تُحفظ الأعداد الوصفية للتصدير فقط.
- لا يتم تعديل أي بيانات في Firebase قبل رفع الملف من لوحة الإدارة والتأكيد الصريح.
