صدى العراق — النسخة المعدلة

التعديلات:
- الشعار الرسمي المرفوع من المستخدم موجود في sadairaq-logo.jpg ويظهر في تسجيل الدخول/إنشاء الحساب وداخل التطبيق.
- العملة الأساسية للمستخدم: USD.
- سعر الصرف ثابت: 5,000 دينار عراقي = 4 USD، أي 1 USD = 1,250 د.ع.
- كل طلب شحن يحفظ amountUsd وamountIqd وexchangeRate.
- جميع طرق الدفع الموجودة في النسخة الأصلية محفوظة ويمكن إدارتها من لوحة الإدارة.
- إضافة مزود SMM أصبحت: اسم المزود + رابط API + مفتاح API، مع اختبار اتصال حقيقي.
- إصلاح HTTP 404 لمسار المزود بإضافة api/smm.php.
- api/smm.php يتصل بالمزود من الخادم ويدعم API القياسي: balance / services / add / status.
- إضافة api/.htaccess لمسار /api/smm.

متطلبات الاستضافة:
- PHP 8+
- cURL مفضل ومفعّل (يوجد بديل allow_url_fopen)
- HTTPS واتصال خارجي
- الاستضافة يجب أن تسمح بقراءة/كتابة ملفات المشروع.
