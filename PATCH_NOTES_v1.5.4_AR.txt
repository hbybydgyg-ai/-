صدى العراق v1.5.4

إصلاح الخدمات والأقسام:
- الخدمة المضافة إلى قسم موجود تُحفظ داخل groups/categories وتظهر للمستخدمين فوراً.
- عند وجود الخدمة مسبقاً مع مزود نفسه، تتم إضافة القسم الجديد إلى نفس الخدمة بدل إنشاء نسخة مكررة.
- الوراثة التلقائية لمنصة القسم تمنع اختفاء القسم عند تبديل Instagram/TikTok وغيرها.
- إضافة ترتيب أسعار: الأقل أولاً / الأعلى أولاً.
- التحقق من القراءة من قاعدة البيانات بعد الاستيراد قبل إغلاق نافذة الاسترداد.
- مراقبة realtime لخدمات Firebase لتحديث واجهة الطلب بدون انتظار إعادة تحميل أو نشر جديد.

أمان:
- جلسات تنتهي بعد 24 ساعة.
- تحديد معدل لمحاولات الدخول وطلبات المزود والطلبات.
- تحديد حجم JSON الوارد.
- منع عرض مفاتيح المزودين ضمن قائمة API العامة؛ مفتاح المزود يطلب من نقطة مخصصة للمسؤول فقط.
- حفظ مفاتيح المزود الحالية عند استخدام replace إذا لم يرسل العميل مفتاحاً جديداً.
- منع عناوين localhost/private/internal من جلب API لتقليل SSRF.
- status/cancel للطلبات مقيد بمالك الطلب في سجل الخادم.
- Cookie آمنة عند العمل خلف HTTPS + HSTS.
