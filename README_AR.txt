صدى العراق — الإصدار 1.5.49

تحديث الكتالوج وواجهة مزود الخدمات:
- فلترة المنصة تُطبّق على كل الفئات والخدمات، وليس خيار «الكل» فقط، وتُخفى الفئات التي لا تحتوي خدمات للمنصة المختارة.
- منع اختلاط خدمات Instagram وTikTok والمنصات الأخرى داخل الفئة نفسها عند التنقل بين المنصات.
- إضافة صور احتياطية SVG مضمنة داخل الصفحة؛ إذا تعذر تحميل ملف صورة أو أيقونة من الاستضافة، يظهر شعار المنصة البديل بدلاً من صورة مكسورة.
- توريث صورة الفئة إلى كل خدماتها، مع تسجيل منصة الصورة الافتراضية لمنع تسرّب أيقونة منصة إلى منصة أخرى عند استخدام فئة تحمل الاسم نفسه.
- إصلاح مزامنة قائمة المزودين: دمج قائمة الخادم وFirebase والنسخة الاحتياطية بدلاً من استبدال القائمة الأحدث بمصدر قديم، وحفظ المزود النشط والتحقق من صلاحيته.
- تحسين واجهة استيراد الخدمات لتكون أوضح على الهاتف، مع مراحل واضحة، صور مصغرة، أسعار وحدود كمية، واختيار الخدمات يدوياً دون تحديد الكل تلقائياً.

لا يحذف هذا الإصدار المستخدمين أو الطلبات أو الخدمات أو بيانات المزودين.

ملفات التشغيل: index.html, server.js, package.json, railway.json, config.json, version.txt, BUILD_ID.txt, api-addon.js وأصول الصور.

النشر: فك ضغط الملف داخل جذر المشروع المرتبط بـ Railway واستبدل الملفات القديمة ثم احفظ وادفع التغييرات إلى GitHub إن كان المشروع مربوطاً به. بعد اكتمال النشر افتح /api/health?ts=رقم-جديد وتأكد من version=1.5.49 وdeploymentConsistent=true.

اختبارات هذه النسخة: فحص صياغة سكربتات JavaScript وملف الخادم، اختبارات قواعد تطبيع المنصات وفلاتر الخدمات والفئات، اختبار fallback للصور، وفحص سلامة ملف ZIP النهائي.
