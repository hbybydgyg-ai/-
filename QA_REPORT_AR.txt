تقرير فحص الإصدار 1.5.78 — صدى العراق
====================================

التعديلات
---------
- تغير زر المستخدم «لوحة التحكم» إلى «حسابي» وأصبح يفتح نافذة الحساب.
- نافذة الحساب تعرض الاسم واسم المستخدم والبريد والهاتف وتاريخ التسجيل والرتبة عندما تكون هذه الحقول متاحة في سجل المستخدم المصادق عليه، مع إحصائيات الطلبات والرصيد والإنفاق والاسترداد والمكافآت.
- أضيفت أداة استيراد قاعدة Base44 مباشرةً داخل صفحة إدارة المستخدمين: رفع ZIP، معاينة قبل الدمج، وتأكيد صريح قبل أي تعديل على قاعدة Firebase.
- صحح عنوان مقياس السجلات القديمة ليعرض السجلات القديمة غير المطابقة فقط، بدلاً من عد السجلات المطابقة مرتين في الملخص.
- أضيف زر لترتيب أكثر المستخدمين طلباً اعتماداً على سجل الطلبات المتاح.
- لم يُضمّن ملف قاعدة البيانات الشخصية ضمن مشروع الكود، ولم تُعدّل قاعدة Firebase الإنتاجية.

الفحوص المنفذة
--------------
- node --check server.js: ناجح.
- تحليل 54 كتلة JavaScript داخل index.html: ناجح.
- فحص ZIP المشروع وسلامة CRC: ناجح.
- فحص ZIP تصدير Base44 وسلامة SQLite باستخدام PRAGMA integrity_check: ناجح.
- قاعدة التصدير الفعلية: 822 مستخدماً، 2,840 طلباً، 1,129 معاملة.
- اختبار تكاملي محلي لمسار /api/admin/legacy-import/upload ثم preview ثم apply، باستخدام قاعدة Firebase محاكية وليست قاعدة الإنتاج: نجح رفع الملف والتحقق منه، ثم أضاف 2,840 طلباً، وعرض 822 سجل مستخدم إجمالي (3 حسابات مطابقة في بيانات الاختبار و819 سجلاً قديماً غير مطابق)، دون أخطاء تحديث للأرصدة أو عدادات الطلبات.
- إعادة الاستيراد التجريبية: 0 طلبات جديدة، 2,840 طلباً موجوداً سابقاً، عدد الطلبات في قاعدة الاختبار بقي 2,840، ولم تتغير عدادات المستخدمين. هذا يختبر منع التكرار في بيئة المحاكاة.
- فحص /api/health محلياً: الإصدار وBuild ID متطابقان.

حدود التحقق المهمة
------------------
الاختبارات التكاملية استعملت خادماً محلياً يحاكي Firebase. لم يتم الوصول إلى قاعدة Firebase الإنتاجية أو تعديلها، ولم نتحقق من بيانات Railway الحية. بعد نشر هذا الإصدار، يجب رفع SadaIraq_Database_Export.zip من صفحة الإدارة > المستخدمون، ومراجعة المعاينة، ثم تأكيد الدمج. لا يمكن اعتبار استعادة بيانات الإنتاج مكتملة قبل رؤية نتيجة الدمج في الموقع الحي.

تيليجرام
--------
لم يُختبر إرسال حقيقي إلى Telegram. التوكن الذي ظهر في المحادثة مكشوف ويجب إلغاؤه عبر BotFather وإنشاء توكن جديد، ثم وضع مفتاح تشفير ثابت ومستقل في Railway Variables واختبار الاتصال والقناة بعد النشر. لا ترسل التوكن أو مفتاح التشفير في المحادثة.
