إضافات الإصدار 1.5.51:
- تثبيت حدود صور الخدمات داخل صفحة الطلب حتى لا تغيّر الصورة الكبيرة تصميم الصفحة.
- تطبيق ترتيب الأقسام المحفوظ من لوحة «الأقسام وترتيبها» في قائمة المستخدم.
- المحافظة على الاسم المحلي للخدمة عند إعادة استيراد نفس خدمة المزود.
- استبدال نموذج معرف Binance بشحن يفتح واتساب الدعم برسالة جاهزة ومبلغ مختار، دون وعد بإضافة تلقائية للرصيد.
- تجميل واجهة API وإضافة اختبار حي للخادم ومفتاح API ونقطة قائمة الخدمات.

ملاحظة تحديث آمن: لا تستبدل مجلد data الموجود في بيئة الإنتاج بملفات البيانات الافتراضية الموجودة داخل الأرشيف. احتفظ ببيانات Railway/قاعدة البيانات كما هي.

صدى العراق — الإصدار 1.5.50

تحديث الكتالوج وواجهة مزود الخدمات:
- فلترة المنصة تُطبّق على كل الفئات والخدمات، وليس خيار «الكل» فقط، وتُخفى الفئات التي لا تحتوي خدمات للمنصة المختارة.
- منع اختلاط خدمات Instagram وTikTok والمنصات الأخرى داخل الفئة نفسها عند التنقل بين المنصات.
- إضافة صور احتياطية SVG مضمنة داخل الصفحة؛ إذا تعذر تحميل ملف صورة أو أيقونة من الاستضافة، يظهر شعار المنصة البديل بدلاً من صورة مكسورة.
- توريث صورة الفئة إلى كل خدماتها، مع تسجيل منصة الصورة الافتراضية لمنع تسرّب أيقونة منصة إلى منصة أخرى عند استخدام فئة تحمل الاسم نفسه.
- إصلاح مزامنة قائمة المزودين: دمج قائمة الخادم وFirebase والنسخة الاحتياطية بدلاً من استبدال القائمة الأحدث بمصدر قديم، وحفظ المزود النشط والتحقق من صلاحيته.
- تحسين واجهة استيراد الخدمات لتكون أوضح على الهاتف، مع مراحل واضحة، صور مصغرة، أسعار وحدود كمية، واختيار الخدمات يدوياً دون تحديد الكل تلقائياً.

لا يحذف هذا الإصدار المستخدمين أو الطلبات أو الخدمات أو بيانات المزودين.

ملفات التشغيل: index.html, server.js, package.json, railway.json, config.json, version.txt, BUILD_ID.txt, api-addon.js وأصول الصور.

النشر: فك ضغط الملف داخل جذر المشروع المرتبط بـ Railway واستبدل الملفات القديمة ثم احفظ وادفع التغييرات إلى GitHub إن كان المشروع مربوطاً به. بعد اكتمال النشر افتح /api/health?ts=رقم-جديد وتأكد من version=1.5.51 وdeploymentConsistent=true.

اختبارات هذه النسخة: فحص صياغة سكربتات JavaScript وملف الخادم، اختبارات قواعد تطبيع المنصات وفلاتر الخدمات والفئات، اختبار fallback للصور، وفحص سلامة ملف ZIP النهائي.


الإصدار 1.5.50: توحيد فلترة المنصة والقسم، عرض صورة القسم على الخدمات التابعة له، إصلاح بديل الصور المكسورة، وإظهار سعر كل 1000 وحدود الكمية بدقة.

مهم لحماية بياناتك: حزمة الإصدار 1.5.50 لا تتضمن ملفات data المحلية حتى لا تستبدل سجلات المستخدمين والطلبات أو إعدادات المزود بملفات افتراضية عند التحديث. عند تحديث مشروع قائم، احتفظ بمجلد data الحالي وأي Railway Volume كما هو. عند أول تشغيل لمشروع جديد، ينشئ الخادم ملفات البيانات الافتراضية تلقائياً.
