صدى العراق — الإصدار 1.5.82
============================
تحسين سرعة الفتح وتحديث بيانات القسم النشط وإصلاح مسار إشعارات Telegram.

أبرز التعديلات:
- ضغط Brotli/Gzip للواجهة والملفات النصية وواجهات JSON المناسبة.
- ETag وLast-Modified وإعادة التحقق من الملفات بدل فرض no-store على كل الملفات.
- تقليل تأخير شاشة البداية، وعدم انتظار المدة الكاملة إذا جهزت الجلسة مبكراً.
- إعادة تحميل بيانات الصفحة النشطة عند التنقل والعودة إلى المتصفح، ثم كل 60 ثانية عندما تكون الصفحة مرئية.
- جعل رسائل Telegram نصية بشكل افتراضي لتجنب تأخير رفع الصورة غير الضروري.
- إرسال الإشعارات إلى الوجهات المتعددة بالتوازي، مع نتيجة منفصلة لكل وجهة.
- مسار اختبار Telegram يتحقق من استجابة API الفعلية قبل عرض نجاح.

مهم للأمان:
- التوكن الذي نشر سابقاً في المحادثة يجب إلغاؤه من BotFather وإنشاء توكن جديد. لا تستخدم التوكن المكشوف ولا تضع أي توكن في GitHub.
- ضبط SADA_ENCRYPTION_KEY في Railway بمفتاح قوي وثابت قبل حفظ توكن جديد من لوحة الإدارة.
- لا يحتوي هذا الملف على توكن فعلي أو قاعدة المستخدمين الخاصة.

النشر:
1. ارفع المشروع الكامل إلى GitHub وانشره عبر Railway كما معتاد، مع الحفاظ على قاعدة البيانات/Volume الحالية.
2. افتح /api/health وتأكد من version=1.5.82 وdeploymentConsistent=true.
3. سجل الدخول إلى لوحة الإدارة واختبر اتصال Telegram ثم إرسال رسالة اختبار إلى الأدمن والقناة كل على حدة.
4. تأكد من وصول رسالة حقيقية قبل اعتبار Telegram جاهزاً. لا تعتبر الاختبار المحلي وحده دليلاً على وصول الإنتاج.

يجب ألا تُستبدل قاعدة البيانات الدائمة الموجودة بملفات data الفارغة داخل حزمة الكود. أبقِ Railway Volume/قاعدة البيانات الإنتاجية متصلة كما هي.
