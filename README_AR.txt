صدى العراق — النسخة المعاد بناؤها من الملف الأصلي

الرفع:
1) ارفع كل الملفات والمجلدات كما هي إلى جذر الاستضافة.
2) يلزم PHP 8.1+، Sessions، JSON، OpenSSL، ويفضل cURL. يوجد fallback عبر HTTPS streams إذا لم يتوفر cURL.
3) المجلد data للملفات الداخلية ويجب أن يكون قابلاً للكتابة من PHP. يوجد .htaccess لمنع الوصول المباشر.

مزود SMM:
- من الإدارة > مزودو SMM API: اسم المزود + رابط API + مفتاح API.
- زر اختبار الاتصال يستخدم /api/smm ثم يتصل بخادم المزود عبر POST.
- هذا يعالج HTTP 404 الناتج عندما تكون صفحات API غير موجودة على الاستضافة.
- API المستعمل في النسخة يدعم صيغة SMM API v2 القياسية: balance, services, add, status.

العملة:
- العملة الرسمية للمستخدم: USD.
- سعر ثابت: 1 USD = 1,250 IQD.
- لذلك 5,000 IQD = 4.00 USD.
- فئات آسياسيل من 1,000 إلى 10,000 IQD بمضاعفات 1,000.

آسياسيل:
- الخطوات: رقم آسياسيل -> رمز SMS -> اختيار المبلغ -> رمز تأكيد التحويل.
- التنفيذ يتم من api/asiacell عبر جلسة PHP، ولا يتم وضع access token داخل HTML.
- بعد نجاح التحويل، يضاف المبلغ المقابل بالدولار إلى رصيد المستخدم في Firebase.
- الرقم المستلم ثابت داخل خادم الموقع في api/asiacell/index.php.
